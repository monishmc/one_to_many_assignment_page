# One-to-Many Assignment Problem

This project implements solutions for one-to-many assignment problems using cost matrices.

## Features

- Basic assignment without requiring each row to have an assignment
- Assignment with at least one column assigned to each row
- Hungarian algorithm-based optimization
- XML input for cost matrices
- CSV output validation matrix

## Technologies Used

- C++
- XML parsing
- CSV output
- Hungarian Algorithm
- Chrono for runtime measurement
